# Ride model production

The source-of-truth is the owner-supplied model geometry. Existing company metrics and project status labels remain independent of these visualisations.

| Asset | Supplied format | Presentation scope |
|---|---|---|
| Observation wheel | MAX | Detailed source geometry; rotor and 30 upright gondolas |
| Swing carousel | MAX | Source canopy, chains, seats and base; rotating assembly |
| Drop tower | SKP | Source tower and passenger carriage; illustrative vertical motion |
| Condor | SKB | Source structure; illustrative upper-assembly rotation |
| Typhoon | SKP | Track and structure; orbit inspection |
| Lightning | DWG | Track, spine, supports and station; orbit inspection |
| Disco Coaster | MAX placement scene | Pending actual ride source; not included in public models |

## Processing

1. Audit native source units, objects, material dependencies and bounds without overwriting source files.
2. Export MAX/DWG through native 3ds Max; inspect DWG entity types and insertion units through AutoCAD Core Console. Read SKP/SKB through the installed SketchUp C API, including hierarchy, materials and UV coordinates.
3. Save a separate imported Blender scene. Keep full source geometry and a separate presentation master.
4. Restore unavailable finishes using explicit procedural material designs. Add lighting, microtexture and presentation controls. Preserve rest-pose geometry and check moving assemblies at several frames.
5. Produce a separate web LOD, consolidate draw calls by moving assembly, retain source UVs, add 2048px finish maps and export compressed GLB animations.
6. Render posters in Blender Cycles; inspect final web models, motion, fallbacks, mobile layout and pause behaviour before publication.

Web posters are rendered at 1920×1080 with Cycles, adaptive sampling up to 96 samples and denoising. The editable masters retain full source detail and a 3840×2160 / 256-sample output preset; that preset is not a claim that a 4K film was rendered. This delivery uses interactive Three.js animation. The viewer uses a less expensive transparent reflective glass material instead of a refraction pass; master scenes and the downloadable GLB retain their detailed material definitions. Normal-map tangent space is generated by the target renderer.

## Source limitations

- The wheel source contains approximately 6.8 million evaluated polygons in Max and 10.1 million triangles after import. Its file name is not used as a verified dimensional specification.
- Several swing-carousel decorative texture files are missing. The untextured decorative portrait plane is hidden in the presentation copy; source geometry remains in the imported master. Replacement wood and coatings are presentation finishes, not a claim about the original installed finish.
- The supplied DiscoCoster placement scene contains site surroundings, not a verified ride assembly. The owner does not know the separate model's location.
- The Lightning DWG references two unavailable external files. Available native 3D solids are used; completeness of absent references is not claimed. Drawing insertion units and exported scene units require an explicit conversion check.
- Original renderer-specific shaders are not treated as transferable validation. Blender PBR materials are recreated in the working scene.
- Ride timing, loads, clearances, safety logic and compliance are not validated by a presentation animation. Typhoon and Lightning have no train-motion claim. Condor secondary hubs are not individually simulated.

## Delivery separation

The website contains lightweight visualisations, not original engineering source files. Full Blender masters, imported scenes, intermediate native exports, dependency reports and reversible build scripts are retained in the local production package. Public access to visualisations does not assign a blanket licence to redistribute original supplied models.
